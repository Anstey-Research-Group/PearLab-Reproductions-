# Contributing

This repository is a learning-oriented, documentation-first project. Contributions are welcome if they improve clarity, reproducibility, or the quality of the experiment notes.

## Guidelines

- Keep changes focused and easy to review.
- If you update the experiment protocol or hardware notes, also update the main ledger.
- If you add or change firmware, include a short note about what changed and why.
- Prefer clear, plain-language documentation over clever formatting.

## Suggested workflow

1. Open or update an issue for the change you want to make.
2. Make the smallest change that addresses the goal.
3. Update the relevant documentation and any related ledger entries.
4. Summarize the update in the changelog.
