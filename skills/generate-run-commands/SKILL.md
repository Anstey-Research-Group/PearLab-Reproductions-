# generate-run-commands

Purpose

Document the workspace run command helpers and provide a skill entry point for creating or updating .vscode/tasks.json run commands that appear in the Agents Run menu.

What it does

- Describes the recommended tasks to expose to agents (validator, read messages, show summary)
- Explains how to add runOptions.runOn: worktreeCreated for setup tasks
- Advises merging new tasks rather than overwriting existing ones

Usage examples

- Edit .vscode/tasks.json to add tasks with "inAgents": true
- Use the generate-run-commands skill to propose run commands and log them to the discussion ledger
- Wrapper usage: python3 scripts/skill_gen_run_commands.py --show  (or --write to write the recommended tasks.json)

Notes

This SKILL.md documents the conventions; the actual code that created tasks.json previously in this repo was generated by the agent tooling.
